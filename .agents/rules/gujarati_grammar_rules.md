# Gujarati Grammar & Orthography Rules (ગુજરાતી વ્યાકરણ અને શાસ્ત્રીય જોડણી નિયમાવલી)

## ૧. 'પર્યાય' પુલ્લિંગ નિયમ (Paryay is Masculine)
જૈન દર્શન અને ગુજરાતી ભાષા વ્યાકરણ અનુસાર **'પર્યાય' શબ્દ સર્વથા 'પુલ્લિંગ' (Masculine Gender)** છે. તેને સ્ત્રીલિંગ ગણીને સ્ત્રીલિંગી ક્રિયાપદ કે વિશેષણ વાપરવું એ વ્યાકરણ દોષ છે.

### ૧.૧ ક્રિયાપદ સુસંગતતા (Verb Agreement)
- `પર્યાય ઉત્પન્ન થયો` (NOT `ઉત્પન્ન થઈ`)
- `પર્યાય બદલાયો` (NOT `બદલાઈ`)
- `પર્યાય પ્રગટ થયો` / `પર્યાય પ્રગટ્યો` (NOT `પ્રગટ થઈ` / `પ્રગટી`)
- `પર્યાય નષ્ટ થયો` (NOT `નષ્ટ થઈ`)
- `પર્યાય પૂરો થયો` (NOT `પૂરી થઈ`)
- `પર્યાય જતો રહ્યો` (NOT `જતી રહી`)
- `પર્યાયો બદલાયા` (NOT `બદલાઈ`)
- `પર્યાયો ઉત્પન્ન થયા` (NOT `ઉત્પન્ન થઈ`)

### ૧.૨ સંબંધક પ્રત્યય (Genitive Case Agreement)
- `દ્રવ્યનો પર્યાય` (NOT `દ્રવ્યની પર્યાય`)
- `તેનો પર્યાય` (NOT `તેની પર્યાય`)
- `આત્માનો પર્યાય` (NOT `આત્માની પર્યાય`)
- `સમયનો પર્યાય` (NOT `સમયની પર્યાય`)
- `અતીતનો પર્યાય` (NOT `અતીતની પર્યાય`)
- `દ્રવ્યના પર્યાયો` (NOT `દ્રવ્યની પર્યાયો`)
- `તેના પર્યાયો` (NOT `તેની પર્યાયો`)
- `સંસારના પર્યાયો` (NOT `સંસારની પર્યાયો`)

### ૧.૩ વિશેષણ સુસંગતતા (Adjective Agreement)
- `બધા પર્યાયો` (NOT `બધી પર્યાયો`)
- `આવો પર્યાય` (NOT `આવી પર્યાય`)
- `નવો પર્યાય` (NOT `નવી પર્યાય`)
- `પર્યાય કેવો?` (NOT `પર્યાય કેવી?`)

## ૨. શાસ્ત્રીય જોડણી અને તત્સમ શબ્દ પ્રમાણીકરણ (Orthography & Tatsama Standard)

આ નિયમો એકવચન, બહુવચન, સામાસિક પદો તેમજ પ્રત્યય (વિભક્તિ, સ્ત્રી-પુલ્લિંગ, ભાવવાચક વગેરે) લાગેલા હોય ત્યારે પણ અક્ષરશઃ લાગુ રહેશે:

| અશુદ્ધ / વર્જિત પ્રયોગ (Incorrect) | પ્રમાણભૂત શુદ્ધ પ્રયોગ (Mandatory Standard) | વ્યાકરણીય / વ્યુત્પત્તિ શાસ્ત્રીય સંદર્ભ |
|---|---|---|
| `તત્વ` / `તત્વો` / `તત્વજ્ઞાન` / `તત્વમીમાંસા` | `તત્ત્વ` / `તત્ત્વો` / `તત્ત્વજ્ઞાન` / `તત્ત્વમીમાંસા` | સંસ્કૃત તત્સમ 'તત્ત્વ' (તત્ + ત્વ) — દ્વિ-તકાર (ત્ત્વ) સંયુક્તાક્ષર જ શુદ્ધ છે. એકવચન, બહુવચન કે પ્રત્યય સહિત સર્વત્ર 'તત્ત્વ' જ વાપરવું. |
| `તાત્વિક` / `તાત્વિકતા` / `તાત્વિકપણે` | `તાત્ત્વિક` / `તાત્ત્વિકતા` / `તાત્ત્વિકપણે` | 'તત્ત્વ' પરથી બનતું વિશેષણ હોવાથી દ્વિ-તકાર (ત્ત્) જળવાવો અનિવાર્ય છે. |
| `સતગુરૂ` / `સતગુરુ` / `સદગુરુ` / `સદગુરૂ` / `સદ્ગુરુ` | `સદ્ગુરૂ` / `સદ્ગુરૂના` / `સદ્ગુરૂઓ` / `સદ્ગુરૂદેવ` | સંસ્કૃત સંધિ નિયમ અનુસાર 'સત્ + ગુરૂ' = 'સદ્ગુરૂ' (દ-હલન્ત અને દીર્ઘ 'રૂ'). વિભક્તિ કે બહુવચનમાં પણ 'સદ્ગુરૂ' રૂપ જ પ્રયોજવું. |
| `મહત્વ` / `મહત્વપૂર્ણ` / `મહત્વનું` | `મહત્ત્વ` / `મહત્ત્વપૂર્ણ` / `મહત્ત્વનું` | સંસ્કૃત તત્સમ 'મહત્ત્વ' (મહત્ + ત્વ) — દ્વિ-તકાર (ત્ત્વ) જ શુદ્ધ છે. |
| `સાક્ષાત` | `સાક્ષાત્` | મૂળ સંસ્કૃત અવ્યય હલન્ત 'સાક્ષાત્' (ત્) તરીકે જ વપરાય છે. |
| `દુખી` / `દુખીઓ` / `દુખીઓને` | `દુઃખી` / `દુઃખીઓ` / `દુઃખીઓને` | સંસ્કૃત તત્સમ વિસર્ગયુક્ત રૂપ 'દુઃખી' જ સાહિત્યિક પ્રમાણભૂત છે. |
| `દુખ` / `દુખો` / `દુખે` / `સુખદુખ` / `દુખદ` | `દુઃખ` / `દુઃખો` / `દુઃખે` / `સુખદુઃખ` / `દુઃખદ` | સંસ્કૃત તત્સમ શબ્દમાં વિસર્ગ (ઃ) અનિવાર્ય છે. |
| `મૂર્છા` / `મૂર્છિત` / `મૂર્છામાં` / `પરિગ્રહ-મૂર્છા` | `મૂર્ચ્છા` / `મૂર્ચ્છિત` / `મૂર્ચ્છામાં` / `પરિગ્રહ-મૂર્ચ્છા` | સંસ્કૃત ધાતુ 'મૂર્ચ્છ્' પરથી બનતો તત્સમ શબ્દ 'ચ્ + છ' (ચ્છ) સંયુક્તાક્ષર ધરાવે છે. |
