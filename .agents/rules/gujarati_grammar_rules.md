# Gujarati Grammar Rule: Paryay is Masculine (પર્યાય પુલ્લિંગ નિયમ)

## નિયમ વિધાન (Rule Definition)
જૈન દર્શન અને ગુજરાતી ભાષા વ્યાકરણ અનુસાર **'પર્યાય' શબ્દ સર્વથા 'પુલ્લિંગ' (Masculine Gender)** છે. તેને સ્ત્રીલિંગ ગણીને સ્ત્રીલિંગી ક્રિયાપદ કે વિશેષણ વાપરવું એ વ્યાકરણ દોષ છે.

### ૧. ક્રિયાપદ સુસંગતતા (Verb Agreement)
- `પર્યાય ઉત્પન્ન થયો` (NOT `ઉત્પન્ન થઈ`)
- `પર્યાય બદલાયો` (NOT `બદલાઈ`)
- `પર્યાય પ્રગટ થયો` / `પર્યાય પ્રગટ્યો` (NOT `પ્રગટ થઈ` / `પ્રગટી`)
- `પર્યાય નષ્ટ થયો` (NOT `નષ્ટ થઈ`)
- `પર્યાય પૂરો થયો` (NOT `પૂરી થઈ`)
- `પર્યાય જતો રહ્યો` (NOT `જતી રહી`)
- `પર્યાયો બદલાયા` (NOT `બદલાઈ`)
- `પર્યાયો ઉત્પન્ન થયા` (NOT `ઉત્પન્ન થઈ`)

### ૨. સંબંધક પ્રત્યય (Genitive Case Agreement)
- `દ્રવ્યનો પર્યાય` (NOT `દ્રવ્યની પર્યાય`)
- `તેનો પર્યાય` (NOT `તેની પર્યાય`)
- `આત્માનો પર્યાય` (NOT `આત્માની પર્યાય`)
- `સમયનો પર્યાય` (NOT `સમયની પર્યાય`)
- `અતીતનો પર્યાય` (NOT `અતીતની પર્યાય`)
- `દ્રવ્યના પર્યાયો` (NOT `દ્રવ્યની પર્યાયો`)
- `તેના પર્યાયો` (NOT `તેની પર્યાયો`)
- `સંસારના પર્યાયો` (NOT `સંસારની પર્યાયો`)

### ૩. વિશેષણ સુસંગતતા (Adjective Agreement)
- `બધા પર્યાયો` (NOT `બધી પર્યાયો`)
- `આવો પર્યાય` (NOT `આવી પર્યાય`)
- `નવો પર્યાય` (NOT `નવી પર્યાય`)
- `પર્યાય કેવો?` (NOT `પર્યાય કેવી?`)
