# નયચક્ષુ — કથાધારા clipart

225 મુખ્ય પ્રકરણો માટે અલગ square clipart. `chapter-image-map.json` canonical mapping છે. CSV અને Markdown તેની માનવીય વાંચન માટેની આવૃત્તિઓ છે.

ચિત્રના filenameમાં ખંડ અને ખંડની અંદરનો પ્રકરણક્રમ છે; મૂળ source filename પણ mappingમાં છે. Printed page numbers હજી નક્કી નથી. HTMLમાં relative path તેની પોતાની location પ્રમાણે resolve કરવો.

Original generated PNG bytes `originals/`માં સુરક્ષિત છે. Root `Image/*.png` પણ મૂળ generated આવૃત્તિની નકલ છે. HTML placement માટે `press/`ની ફાઇલ અને canonical mappingનો `html_src` વાપરવો. Generated, pixel-validated, visually reviewed અને press-approved સ્થિતિઓ અલગ છે. કોઈ assetને human press approval મળેલું નથી.

સફેદ પૃષ્ઠભૂમિ, 1:1, monochrome/grayscale; 50 mm placement પર effective DPI QA નોંધાશે. 300 DPI photo threshold ઉપરાંત line art માટે 600 DPI લક્ષ્ય છે. Bleed/profile/PDF-X integration HTML/PDF production વખતે અલગ તપાસવાના છે.
