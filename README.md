# નય પ્રકાશ (Naya Prakash): ૨૦૩ નય મહાગ્રંથ નિર્માણ તંત્ર
### Agentic Book Writing Workflow for 203 Jain Nayas

જૈન દર્શનના નય રહસ્ય (Epistemological Perspectives) પર આધારિત ૨૦૩ નયોનો ૭ ખંડોમાં સંપૂર્ણ શુદ્ધ સાહિત્યિક ગુજરાતી ભાષામાં પ્રમાણભૂત મહાગ્રંથ નિર્માણ તંત્ર.

## 📂 પ્રોજેક્ટ માળખું (Project Structure)

આ રિપોઝિટરીમાં ૨૦૩ જૈન નયોના લેખન માટેના બે વિશિષ્ટ વર્કફ્લો ગોઠવવામાં આવ્યા છે:

1. **[`vistrut/`](./vistrut)**: **વિસ્તૃત મહાગ્રંથ વર્કફ્લો (Expanded Edition)**
   - પ્રત્યેક નય પર ૧૦-પોઈન્ટ ફોર્મેટ સાથે ઊંડાણપૂર્વકનો ૨૫૦૦-૩૫૦૦+ શબ્દોનો વિસ્તૃત સાહિત્યિક ગુજરાતી અધ્યાય.
   - ઓશો-શૈલીના ૩ અદ્વિતીય આધ્યાત્મિક દૃષ્ટાંતો (કુલ ૬૦૯ અદ્વિતીય ઉદાહરણો).
   - તાર્કિક વિવેચન (~૧૦૦૦ શબ્દો), વ્યવહારિક સમજ (~૩૦૦ શબ્દો), દાર્શનિક સમજ (૨૫૦-૩૦૦ શબ્દો), સૈદ્ધાંતિક સમજ, ૫ ધ્યાનાત્મક સાધના-પ્રયોગો, ડીપ ડાઈવ (૩૫૦-૬૦૦ શબ્દો) અને મંઝિલગામી વલણ (૧૮૦-૨૫૦ શબ્દો).
   - શાસ્ત્રીય સંદર્ભ ગ્રંથાલય (આલાપપદ્ધતિ, નયવિંશિકા, પંચાધ્યાયી, નયપ્રદીપ વગેરે) સાથે સંકલિત.

2. **[`sankshipt/`](./sankshipt)**: **સંક્ષિપ્ત આવૃત્તિ વર્કફ્લો (Concise Edition - Coming Soon)**
   - ૨૦૩ નયોનો સંક્ષિપ્ત, સરળ અને સારગર્ભિત સ્વાધ્યાયલક્ષી પરિચય.

## 🏛️ સપ્ત ખંડ વિભાજન (7 Khandas)

1. **પ્રથમ ખંડ: નૈગમ નય** (જ્ઞાનનય - દ્રવ્યાર્થિક) — નય ક્રમાંક ૧ થી ૩૫ (૩૫ અધ્યાય)
2. **દ્વિતીય ખંડ: સંગ્રહ નય** (અર્થનય - દ્રવ્યાર્થિક) — નય ક્રમાંક ૩૬ થી ૬૭ (૩૨ અધ્યાય)
3. **તૃતીય ખંડ: વ્યવહાર નય** (અર્થનય - દ્રવ્યાર્થિક) — નય ક્રમાંક ૬૮ થી ૧૦૫ (૩૮ અધ્યાય)
4. **ચતુર્થ ખંડ: ઋજુસૂત્ર નય** (અર્થનય - પર્યાયાર્થિક) — નય ક્રમાંક ૧૦૬ થી ૧૩૫ (૩૦ અધ્યાય)
5. **પંચમ ખંડ: શબ્દનય** (શબ્દનય - પર્યાયાર્થિક) — નય ક્રમાંક ૧૩૬ થી ૧૫૯ (૨૪ અધ્યાય)
6. **ષષ્ઠ ખંડ: સમભિરૂઢ નય** (શબ્દનય - પર્યાયાર્થિક) — નય ક્રમાંક ૧૬૦ થી ૧૮૧ (૨૨ અધ્યાય)
7. **સપ્તમ ખંડ: એવંભૂત નય** (શબ્દનય - પર્યાયાર્થિક) — નય ક્રમાંક ૧૮૨ થી ૨૦૩ (૨૨ અધ્યાય)

## 🚀 વિસ્તૃત વર્કફ્લોનો ઉપયોગ (Quick Start)

વિસ્તૃત વર્કફ્લો ચલાવવા માટે `vistrut` ડિરેક્ટરીમાં જાઓ:

```powershell
cd vistrut

# પ્રગતિ સ્થિતિ જુઓ (Status Dashboard)
python -m src.cli status

# અધ્યાય ૧ ચકાસો (Validate Chapter 1)
python -m src.cli validate --file output/khanda_1_naigam/chapter_001_bhuta_naigam_naya_gu.md

# સંપૂર્ણ પુસ્તક સંકલિત કરો (Compile Master Book)
python -m src.cli compile

# ટેસ્ટ સ્યુટ ચલાવો (Run Tests)
python -m pytest tests/
```
