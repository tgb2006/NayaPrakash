# નય-ચક્ષુ r06 — અનુક્રમણિકા ચકાસણી

- અનુક્રમણિકાની ૨૪૮ એન્ટ્રીઓ ૧૧ પાનાં (૧૨–૨૨)માં ફરી ગોઠવી. ઉપયોગી લખાણ વિસ્તારની ભરાવટ ૮૧.૬–૮૫.૬% છે. પહેલાં પાનાં ૧૨ અને ૧૩ની ભરાવટ અનુક્રમે ૫૦.૪% અને ૪૮.૩% હતી. ખંડનું શીર્ષક તેની પહેલી એન્ટ્રી સાથે છે.
- r05 સામે સરખામણીમાં અનુક્રમણિકાની એન્ટ્રીઓ, ક્રમ, લિંક્સ અને છાપેલા પાનાં નંબરો સરખાં છે. અનુક્રમણિકા સિવાય દરેક HTML પાનું સરખું છે. પહેલું પ્રકરણ પાના ૫૮ પર છે અને પુસ્તક ૫૭૪ પાનાંનું છે.
- ૮,૫૧૮ સ્રોત બ્લૉકની HTML તપાસ અને ૬.૫ × ૯.૫ ઇંચનાં ૫૭૪ પાનાંની PDF તપાસ પસાર થઈ. ૧૦ એમ્બેડેડ ફૉન્ટ, ૨૨૫ ચિત્ર અને અનુક્રમણિકાનાં તમામ પાનાં સહિત ૧૫ રેન્ડર ચકાસાયાં. પાનાં ૧૨–૧૩ની દૃશ્ય તપાસ કરી.
