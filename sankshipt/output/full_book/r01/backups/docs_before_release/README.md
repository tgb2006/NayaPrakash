જૈન દર્શનના નય રહસ્ય (Epistemological Perspectives & Standpoints) પર આધારિત ૨૦૩ નયોનો ૭ ખંડોમાં સંપૂર્ણ ૧૦૦% અણીશુદ્ધ સાહિત્યિક ગુજરાતી ભાષામાં પ્રમાણભૂત મહાગ્રંથ નિર્માણ તંત્ર.

## 📂 પ્રોજેક્ટ માળખું અને આવૃત્તિઓ (Dual-Workflow Architecture)

આ રિપોઝિટરીમાં ૨૦૩ જૈન નયોના લેખન માટે બે વિશિષ્ટ સમાંતર વર્કફ્લો ગોઠવવામાં આવ્યા છે:

```
NayaPrakash_Book/
├── vistrut/             # [વિસ્તૃત મહાગ્રંથ] ૧૦-પોઈન્ટ ઊંડાણપૂર્વકનો સંશોધન ગ્રંથ (~૩,૫૦૦ શબ્દો/નય)
└── sankshipt/           # [સંક્ષિપ્ત ૨-પેજ આવૃત્તિ] A5 સામસામેના બે પાના (૫૪૦-૬૩૦ શબ્દો/નય)
```

### ૧. [`sankshipt/`](./sankshipt): નય-ચક્ષુ — નયનું જ્ઞાન, સંશયનું સમાધાન (સંક્ષિપ્ત ૨-પેજ A5 આવૃત્તિ)
- **લક્ષ્ય**: એક જ સુવાચ્ય પુસ્તકમાં ૨૦૩ નયોનો કન્સેપ્ટ રસપ્રદ, સ્વાદિષ્ટ, અલંકારિક અને સરળ શૈલીમાં રજૂ કરવો.
- **પાના માળખું (Facing 2 Pages)**:
  - **ડાબું પાનું (પાનું ૧)**: નય વિવેચન (૪૫%), વ્યવહારિક જીવનમાં વિનિયોગ (૪૫%), કાવ્યાત્મક બોધસૂત્ર, સાધના-સંકેત (~૨૪૦-૩૩૦ શબ્દો).
  - **જમણું પાનું (પાનું ૨)**: પ્રસંગ (૫૦-૬૦%: પિપાસા [મૂંઝવણ/વલયો/પ્રશ્નાર્થ] + પાન [નય-દ્રષ્ટિથી સમાધાન/વિશ્રામ]) અને વિવેક-દર્શન (૪૦%: એકાંત દર્શન [૨૦%] + અનેકાંત દર્શન [૨૦%]) (~૨૫૦-૩૪૦ શબ્દો).
- **કુલ શબ્દો**: ~૫૪૦ થી ૬૩૦ શબ્દો પ્રતિ નય.
- **પુસ્તક કદ**: ૨૦૩ નય × ૨ પાના = ૪૦૬ પાના (+ ૭ ખંડ પરિચય) = કુલ ~૪૩૫ થી ૪૪૫ પાનાની એક જ આકર્ષક A5 પુસ્તક.

### ૨. [`vistrut/`](./vistrut): વિસ્તૃત મહાગ્રંથ (Expanded Comprehensive Treatise)
- **લક્ષ્ય**: જૈન નયવાદ પર સર્વાંગી, ગહન શાસ્ત્રીય અને તાર્કિક મહાગ્રંથ.
- **પ્રકરણ માળખું (૧૦-પોઈન્ટ ફોર્મેટ)**:
  - પરિચય, શાસ્ત્રીય વ્યાખ્યા, તાર્કિક વિવેચન (~૧૦૦૦ શબ્દો), વ્યવહારિક સમજ (~૩૦૦ શબ્દો), દાર્શનિક સમજ (~૩૦૦ શબ્દો), સૈદ્ધાંતિક સમજ, ૫ સાધના-પ્રયોગો, ૩ ઓશો-શૈલીના દૃષ્ટાંતો (કુલ ૬૦૯ અદ્વિતીય વાર્તાઓ), ડીપ ડાઈવ (~૬૦૦ શબ્દો), મંઝિલગામી વલણ.
- **કુલ શબ્દો**: ~૨,૫૦૦ થી ૩,૫૦૦+ શબ્દો પ્રતિ નય.

## 🚀 ઝડપી શરૂઆત (Quick Start)

### સંક્ષિપ્ત આવૃત્તિ ચલાવવા માટે:
```powershell
cd sankshipt

# પ્રગતિ સ્થિતિ જુઓ
python -m src.cli status

# નય ક્રમાંક ૨ માટે પ્રોમ્પ્ટ મેળવો
python -m src.cli prompt --id 2

# અધ્યાય ચકાસો અને રજિસ્ટર કરો
python -m src.cli validate --file output/khanda_1_naigam/chapter_001_bhuta_naigam_naya_gu.md
python -m src.cli register --file output/khanda_1_naigam/chapter_001_bhuta_naigam_naya_gu.md --id 1

# સંપૂર્ણ પુસ્તક કમ્પાઈલ કરો
python -m src.cli compile
```

### વિસ્તૃત આવૃત્તિ ચલાવવા માટે:
```powershell
cd vistrut
python -m src.cli status
python -m src.cli compile
```
