# ગુજરાતી જોડણી અને પ્રૂફ ચકાસણી

| ટાળવાની જોડણી | પુસ્તકમાં માન્ય જોડણી |
| --- | --- |
| તત્વ | તત્ત્વ |
| સતગુરૂ, સતગુરુ, સદગુરુ, સદગુરૂ, સદ્ગુરુ | સદ્ગુરૂ |
| મહત્વ | મહત્ત્વ |
| સાક્ષાત | સાક્ષાત્ |
| તાત્વિક | તાત્ત્વિક |
| દુખી | દુઃખી |
| દુખ | દુઃખ |
| મૂર્છા | મૂર્ચ્છા |

એકવચન, બહુવચન, પ્રત્યયવાળાં રૂપો અને સમાસમાં પણ જોડણી લાગુ પડે છે. તત્ત્વોમાં, આત્મતત્ત્વની, સદ્ગુરૂના, મહત્ત્વપૂર્ણ, દુઃખીઓ અને મૂર્ચ્છામાં જેવા રૂપોમાં શબ્દનો પ્રત્યય જાળવવો. શાશ્વતત્વ, મૂર્તત્વ, મુક્તત્વ અને નિમિત્તત્વમાં સ્વતંત્ર ‘ત્વ’ પ્રત્યય જાળવવો.

લેખન અને સંપાદન પછી `python sankshipt/production/gujarati_spelling.py` ચલાવવું. તે વર્તમાન પ્રકરણો, પ્રસ્તાવના, સામાન્ય પ્રકરણો, ખંડ પ્રવેશ, પરિશિષ્ટ તથા સંકલિત પુસ્તક અને અનુક્રમણિકામાં ખોટી જોડણી હોય તો ફાઇલ અને લાઇન બતાવે છે. સંપૂર્ણ પુસ્તકનું બિલ્ડ પણ આ તપાસ કરે છે અને ભૂલ મળે તો અટકે છે.

નિકાસ પહેલાં અંતિમ HTML અને PDFમાં શીર્ષકો, મુખ્ય લખાણ અને પ્રત્યયવાળાં રૂપોના નમૂના સરખાવવા.
