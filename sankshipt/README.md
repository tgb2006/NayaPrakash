# નય પ્રકાશ: સંક્ષિપ્ત ૨-પેજ આવૃત્તિ વર્કફ્લો (Sankshipt 2-Page A5 Edition)

જૈન દર્શનના ૨૦૩ નયો પર આધારિત આ સંક્ષિપ્ત આવૃત્તિ પુસ્તક નિર્માણ તંત્ર છે. આ આવૃત્તિ ખાસ કરીને **A5 સાઈઝના સામસામેના બે પાના (Facing 2 Pages)** માં પ્રત્યેક નયને રસપ્રદ, આબાલગોપાલ સુબોધ, અલંકારિક, સ્વાદિષ્ટ અને તત્વસ્પર્શી શૈલીમાં રજૂ કરવા માટે રચાયેલ છે.

---

## 📖 ૨-પેજ A5 રચનાત્મક માળખું (Facing-Page Layout)

પ્રત્યેક અધ્યાય ચોક્કસ **૫૩૦ થી ૬૨૦ શબ્દો** માં બે સામસામેના પૃષ્ઠોમાં સુગ્રથિત થાય છે:

```
┌───────────────────────────────────────────────┐   ┌───────────────────────────────────────────────┐
│     ડાબું પાનું (PAGE 1: સંપૂર્ણ નય વિવેચન)     │   │   જમણું પાનું (PAGE 2: પ્રસંગ & વિવેક-દર્શન)     │
├───────────────────────────────────────────────┤   ├───────────────────────────────────────────────┤
│ • શીર્ષક અને સંક્ષિપ્ત આગમ પરિચય               │   │ • પ્રસંગ: પિપાસા અને પાન (૫૦% થી ૬૦% ભાગ)     │
│ • નય વિવેચન (આબાલગોપાલ સુબોધ, ~૨૪૦-૨૭૦ શબ્દો) │   │   - પિપાસા: મૂંઝવણ, અટકળો, વલયો, પ્રશ્નાર્થ   │
│   - સરળ અર્થ અને ઓળખ                         │   │   - પાન: નય-દ્રષ્ટિથી સમાધાન, માર્ગ, વિશ્રામ   │
│   - આબાલગોપાલ પ્રસિદ્ધ ઉદાહરણો                │   │ • વિવેક-દર્શન: એકાંત અને અનેકાંત (૪૦% ભાગ)    │
│   - દ્રષ્ટિનો ભીતરી મર્મ                      │   │   - એકાંત દર્શન (૨૦%): જડતા/કદાગ્રહના નુકસાન  │
│ • કાવ્યાત્મક બોધસૂત્ર (૨ પંક્તિ - ~૨૦-૨૫ શબ્દો) │   │   - અનેકાંત દર્શન (૨૦%): સમન્વયનું સૌંદર્ય    │
│   (નયનું સ્વરૂપ + સાધના સંકેત બંને સાથે)       │   │                                               │
│ (કુલ ડાબું પાનું: ~૨૩૦ થી ૩૦૦ શબ્દો)           │   │ (કુલ જમણું પાનું: ~૨૫૦ થી ૩૨૦ શબ્દો)           │
└───────────────────────────────────────────────┘   └───────────────────────────────────────────────┘
```

### ડાબું પાનું (PAGE 1: સંપૂર્ણ નય વિવેચન & કાવ્યાત્મક બોધસૂત્ર)
1. **નય વિવેચન (~૨૪૦ થી ૨૭૦ શબ્દો)**:
   - દર્શનથી સાવ અજાણ કે અબુધ વ્યક્તિ પણ સમજી શકે તેવી આબાલગોપાલ સુબોધ શૈલી.
   - સુવાચ્ય ઉપ-વિભાગો:
     - *સરળ અર્થ અને ઓળખ*: નયનું સીધું સાદું લક્ષણ.
     - *આબાલગોપાલ પ્રસિદ્ધ ઉદાહરણો*: ઘર, પરિવાર, દિવાળી, બીજ, પાણી અને રોજિંદા જીવનના દૃષ્ટાંતો.
     - *દ્રષ્ટિનો ભીતરી મર્મ*: કાળ અને વસ્તુના સત્-સાતત્યની ગૂઢ છણાવટ.
2. **કાવ્યાત્મક બોધસૂત્ર (~૨૦-૨૫ શબ્દો)**:
   - કેવળ ૨ પંક્તિનો ગેય દોહરો જેમાં **નયનું સ્વરૂપ** અને ભીતરી શાંતિની **સાધના** બંને એક સાથે વણાઈ જાય છે.

### જમણું પાનું (PAGE 2: પ્રસંગ અને વિવેક-દર્શન)
1. **પ્રસંગ: [વાર્તા શીર્ષક] (૫૦% થી ૬૦% ભાગ - ~૧૫૦-૧૮૦ શબ્દો)**:
   - **પિપાસા (પ્રથમ ચરણ)**: વ્યક્તિની મૂંઝવણ, અટકળો, માનસિક વલયોમાં અટકી પડવું જ્યાં કોઈ રસ્તો ન સૂઝે... અને છેલ્લે પ્રશ્નાર્થ: *"આમાંથી શું રસ્તો?"*
   - **પાન (ઉત્તર ચરણ)**: નયની દ્રષ્ટિ આપવામાં આવે જે મૂંઝવણનું નિવારણ અને શંકાનું સમાધાન બને. ઉકેલ, માર્ગ અને મંઝિલ તરફ દોરી જાય, અને અંતરમાં અપૂર્વ વિશ્રામ છવાઈ જાય.
2. **વિવેક-દર્શન: એકાંત અને અનેકાંત (૪૦% ભાગ - ~૧૧૦-૧૩૦ શબ્દો)**:
   - **એકાંત દર્શન (૨૦% ભાગ)**: આ નય-દ્રષ્ટિ જો જીદ, કદાગ્રહ કે જડ બને તો કેવું પરિણામ આવે અને કેવી સંકુચિતતા તથા ગેરલાભો થાય.
   - **અનેકાંત દર્શન (૨૦% ભાગ)**: આજ નય-દ્રષ્ટિ જો યાત્રા, સમન્વયનો દ્રષ્ટિકોણ, મંઝિલગામી અને નિરાગ્રહી બને તો તેનું કેટલું અદ્ભુત સૌંદર્ય પ્રગટે.

## 🛠️ કમાન્ડ લાઈન ઈન્ટરફેસ (CLI Commands)

```powershell
cd sankshipt

# ૧. પ્રગતિ સ્થિતિ જુઓ (Status Dashboard)
python -m src.cli status

# ૨. કોઈ નય માટે લેખન પ્રોમ્પ્ટ મેળવો (Generate Prompt for Naya ID)
python -m src.cli prompt --id 2

# ૩. લખાયેલ અધ્યાયની પાના-વાર શબ્દસંખ્યા અને અહિંસા ચકાસો (Validate)
python -m src.cli validate --file output/khanda_1_naigam/chapter_001_bhuta_naigam_naya_gu.md

# ૪. અધ્યાય ચકાસીને ટ્રેકરમાં રજિસ્ટર કરો (Register)
python -m src.cli register --file output/khanda_1_naigam/chapter_001_bhuta_naigam_naya_gu.md --id 1

# ૫. સંપૂર્ણ પુસ્તક અને અનુક્રમણિકા સંકલિત કરો (Compile Master Book)
python -m src.cli compile

# ૬. નોંધાયેલા પ્રસંગો/કથાઓ જુઓ
python -m src.cli examples

# ૭. યુનિટ ટેસ્ટ્સ ચલાવો (Run Pytest)
python -m pytest tests/
```
