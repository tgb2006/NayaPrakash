# નય પ્રકાશ: સંક્ષિપ્ત ૨-પેજ આવૃત્તિ વર્કફ્લો (Sankshipt 2-Page A5 Edition)

જૈન દર્શનના ૨૦૩ નયો પર આધારિત આ સંક્ષિપ્ત આવૃત્તિ પુસ્તક નિર્માણ તંત્ર છે. આ આવૃત્તિ ખાસ કરીને **A5 સાઈઝના સામસામેના બે પાના (Facing 2 Pages)** માં પ્રત્યેક નયને રસપ્રદ, અલંકારિક, સરળ સુગમ, સ્વાદિષ્ટ અને તત્વસ્પર્શી શૈલીમાં પૂર્ણ કરવા માટે રચાયેલ છે.

---

## 📖 ૨-પેજ A5 રચનાત્મક માળખું (Facing-Page Layout)

પ્રત્યેક અધ્યાય ચોક્કસ **૫૪૦ થી ૬૩૦ શબ્દો** માં બે સામસામેના પૃષ્ઠોમાં સુગ્રથિત થાય છે:

```
┌───────────────────────────────────────────────┐   ┌───────────────────────────────────────────────┐
│     ડાબું પાનું (PAGE 1: સૈદ્ધાંતિક & વ્યવહાર)    │   │   જમણું પાનું (PAGE 2: પ્રસંગ & વિવેક-દર્શન)     │
├───────────────────────────────────────────────┤   ├───────────────────────────────────────────────┤
│ • શીર્ષક અને સંક્ષિપ્ત માહિતી                  │   │ • પ્રસંગ: પિપાસા અને પાન (૫૦% થી ૬૦% ભાગ)     │
│ • નય વિવેચન (૪૫% ભાગ: વ્યાખ્યા, સમજ, ઉદાહરણ) │   │   - પિપાસા: મૂંઝવણ, અટકળો, વલયો, પ્રશ્નાર્થ   │
│ • વ્યવહારિક જીવનમાં વિનિયોગ (૪૫% ભાગ)          │   │   - પાન: નય-દ્રષ્ટિથી સમાધાન, માર્ગ, વિશ્રામ   │
│ • કાવ્યાત્મક બોધસૂત્ર (કંઠસ્થ થાય તેવો દોહરો)   │   │ • વિવેક-દર્શન: એકાંત અને અનેકાંત (૪૦% ભાગ)    │
│ • સાધના-સંકેત (પરમ વિશ્રામ માટે કેવળ ૧ લાઈન)   │   │   - એકાંત દર્શન (૨૦%): જડતા/કદાગ્રહના નુકસાન  │
│                                               │   │   - અનેકાંત દર્શન (૨૦%): સમન્વયનું સૌંદર્ય    │
│ (કુલ ડાબું પાનું: ~૨૪૦ થી ૩૩૦ શબ્દો)           │   │ (કુલ જમણું પાનું: ~૨૫૦ થી ૩૪૦ શબ્દો)           │
└───────────────────────────────────────────────┘   └───────────────────────────────────────────────┘
```

### ડાબું પાનું (PAGE 1: સૈદ્ધાંતિક અને વ્યવહારિક સ્પષ્ટતા)
1. **નય વિવેચન (૪૫% ભાગ - ~૧૨૦-૧૪૦ શબ્દો)**: નયની વ્યાખ્યા, સમજૂતી અને રોચક ઉદાહરણ; પારિભાષિક ક્લિષ્ટતા રહિત, સરળ, સ્વાદિષ્ટ અને અલંકારિક ભાષામાં સંપૂર્ણ સ્પષ્ટતા.
2. **વ્યવહારિક જીવનમાં વિનિયોગ (૪૫% ભાગ - ~૧૨૦-૧૪૦ શબ્દો)**: રોજિંદા જીવનમાં ઉપયોગ, સંબંધોમાં લાભ, ક્ષમા-ધીરજ જેવા ગુણોનો વિકાસ અને વ્યવહારિક સમસ્યાઓનું સમાધાન.
3. **કાવ્યાત્મક બોધસૂત્ર (~૨૦-૨૫ શબ્દો)**: આખો નય મોઢે થઈ જાય અને હૃદયસ્થ બને તેવો ગેય છંદોબદ્ધ દોહરો.
4. **સાધના-સંકેત (કેવળ ૧ લાઈન - ~૧૨-૧૮ શબ્દો)**: ભીતરના પરમ વિશ્રામ તરફ સરકવા માટે એક જ પંક્તિનો માર્મિક સંકેત.

### જમણું પાનું (PAGE 2: પ્રસંગ અને વિવેક-દર્શન)
1. **પ્રસંગ: [વાર્તા શીર્ષક] (૫૦% થી ૬૦% ભાગ - ~૧૫૦-૧૮૦ શબ્દો)**:
   - **પિપાસા (પ્રથમ ચરણ)**: વ્યક્તિની મૂંઝવણ, અટકળો, માનસિક વલયોમાં અટકી પડવું જ્યાં કોઈ રસ્તો ન સૂઝે... અને છેલ્લે પ્રશ્નાર્થ: *"આમાંથી શું રસ્તો?"*
   - **પાન (ઉત્તર ચરણ)**: નયની દ્રષ્ટિ આપવામાં આવે જે મૂંઝવણનું નિવારણ અને શંકાનું સમાધાન બને. ઉકેલ, માર્ગ અને મંઝિલ તરફ દોરી જાય, અને અંતરમાં અપૂર્વ વિશ્રામ છવાઈ જાય.
2. **વિવેક-દર્શન: એકાંત અને અનેકાંત (૪૦% ભાગ - ~૧૨૦-૧૪૦ શબ્દો)**:
   - **એકાંત દર્શન (૨૦% ભાગ)**: આ નય-દ્રષ્ટિ જો જીદ, કદાગ્રહ કે જડ બને તો કેવું પરિણામ આવે અને કેવી સંકુચિતતા તથા ગેરલાભો થાય.
   - **અનેકાંત દર્શન (૨૦% ભાગ)**: આજ નય-દ્રષ્ટિ જો યાત્રા, સમન્વયનો દ્રષ્ટિકોણ, મંઝિલગામી અને નિરાગ્રહી બને તો તેનું કેટલું અદ્ભુત સૌંદર્ય પ્રગટે.

## 🛠️ કમાન્ડ લાઈન ઈન્ટરફેસ (CLI Commands)

`sankshipt/` ડિરેક્ટરીમાંથી:

```powershell
# ૧. પ્રગતિ સ્થિતિ જુઓ (Status Dashboard)
python -m src.cli status

# ૨. કોઈ નય માટે લેખન પ્રોમ્પ્ટ મેળવો (Generate Prompt for Naya ID)
python -m src.cli prompt --id 2

# ૩. લખાયેલ અધ્યાયની પાના-વાર શબ્દસંખ્યા અને અહિંસા ચકાસો (Validate)
python -m src.cli validate --file output/khanda_1_naigam/chapter_001_bhuta_naigam_naya_gu.md

# ૪. અધ્યાય ચકાસીને ટ્રેકરમાં રજિસ્ટર કરો (Register)
python -m src.cli register --file output/khanda_1_naigam/chapter_001_bhuta_naigam_naya_gu.md --id 1

# ૫. સંપૂર્ણ પુસ્તક અને અનુક્રમણિકા સંકલિત કરો (Compile Master Book)
python -m src.cli compile

# ૬. નોંધાયેલા પ્રસંગો/કથાઓ જુઓ
python -m src.cli examples

# ૭. યુનિટ ટેસ્ટ્સ ચલાવો (Run Pytest)
python -m pytest tests/
```

## 📊 પુસ્તકની અંદાજિત કદ ગણતરી (Book Page Count)

- ૨૦૩ નય × ૨ પાના = **૪૦૬ પાના**
- ૭ ખંડ પ્રવેશ પ્રકરણો = **૧૪ થી ૨૧ પાના**
- પ્રસ્તાવના, પારિભાષિક કોશ, અનુક્રમણિકા = **~૧૫ પાના**
- **કુલ પુસ્તક**: આશરે **૪૩૫ થી ૪૪૫ પાના (A5 સાઈઝ)**, જે એક જ સુંદર ગ્રંથમાં અત્યંત આકર્ષક રીતે સમાઈ જશે.
