# નય પ્રકાશ: સંક્ષિપ્ત ૨-પેજ આવૃત્તિ વર્કફ્લો (Sankshipt 2-Page A5 Edition)

જૈન દર્શનના ૨૦૩ નયો પર આધારિત આ સંક્ષિપ્ત આવૃત્તિ પુસ્તક નિર્માણ તંત્ર છે. આ આવૃત્તિ ખાસ કરીને **A5 સાઈઝના સામસામેના બે પાના (Facing 2 Pages)** માં પ્રત્યેક નયને પૂર્ણ કરવા માટે રચાયેલ છે.

---

## 📖 ૨-પેજ A5 રચનાત્મક માળખું (Facing-Page Layout)

પ્રત્યેક અધ્યાય ચોક્કસ **૫૫૦ થી ૬૫૦ શબ્દો** માં સમાપ્ત થાય છે જેથી પુસ્તક છપાય ત્યારે ડાબું અને જમણું પાનું એક સાથે વાંચી શકાય:

```
┌─────────────────────────────────┐   ┌─────────────────────────────────┐
│ ડાબું પાનું (Page 1: દર્શન & વ્યવહાર)│   │ જમણું પાનું (Page 2: નવલિકા)      │
├─────────────────────────────────┤   ├─────────────────────────────────┤
│ • શીર્ષક & શાસ્ત્રીય સંદર્ભ       │   │ • સંપૂર્ણ ટૂંકી નવલિકા             │
│ • સૂત્રાર્થ અને જોવાનો અભિગમ      │   │   (ઓશો-શૈલીની હૃદયસ્પર્શી વાર્તા)│
│ • વ્યવહારિક જીવનમાં વિનિયોગ      │   │                                 │
│ • સાધના-મર્મ                    │   │                                 │
│ • બોધ-સૂત્ર                      │   │                                 │
│ (કુલ ૨૫૦ થી ૩૨૦ શબ્દો)           │   │ (કુલ ૩૦૦ થી ૩૬૦ શબ્દો)           │
└─────────────────────────────────┘   └─────────────────────────────────┘
```

- **ડાબું પાનું (પાનું ૧)**:
  1. **સૂત્રાર્થ અને જોવાનો અભિગમ**: નયની તાત્વિક વ્યાખ્યા અને જોવાની દિશા (~૭૦-૯૦ શબ્દો).
  2. **વ્યવહારિક જીવનમાં વિનિયોગ**: સંબંધો, નિર્ણય અને દૈનિક વ્યવહારમાં ઉપયોગ (~૭૦-૯૦ શબ્દો).
  3. **સાધના-મર્મ**: ધ્યાન, આત્મનિરીક્ષણ અને સાક્ષીભાવ (~૭૦-૯૦ શબ્દો).
  4. **બોધ-સૂત્ર**: એક સુવર્ણ સ્મરણિકા પંક્તિ (~૧૫-૨૫ શબ્દો).

- **જમણું પાનું (પાનું ૨)**:
  5. **નવલિકા**: સંપૂર્ણ ટૂંકી બોધકથા (~૩૦૦-૩૬૦ શબ્દો, શરૂઆત, દ્વંદ્વ અને આધ્યાત્મિક પરિસમાપ્તિ સાથે).

## 🛠️ કમાન્ડ લાઈન ઈન્ટરફેસ (CLI Commands)

`sankshipt/` ડિરેક્ટરીમાંથી નીચે મુજબ કમાન્ડ ચલાવી શકાય છે:

```powershell
# ૧. પ્રગતિ સ્થિતિ જુઓ (Status Dashboard)
python -m src.cli status

# ૨. કોઈ નય માટે લેખન પ્રોમ્પ્ટ મેળવો (Generate Prompt for Naya ID)
python -m src.cli prompt --id 2

# ૩. લખાયેલ અધ્યાયની પાના-વાર શબ્દસંખ્યા અને અહિંસા ચકાસો (Validate)
python -m src.cli validate --file output/khanda_1_naigam/chapter_001_bhuta_naigam_naya_gu.md

# ૪. અધ્યાય ચકાસીને ટ્રેકરમાં રજિસ્ટર કરો (Register)
python -m src.cli register --file output/khanda_1_naigam/chapter_001_bhuta_naigam_naya_gu.md --id 1

# ૫. સંપૂર્ણ પુસ્તક અને અનુક્રમણિકા સંકલિત કરો (Compile Master Book)
python -m src.cli compile

# ૬. ૭ ખંડોની યાદી જુઓ
python -m src.cli khandas

# ૭. નોંધાયેલી નવલિકાઓ જુઓ
python -m src.cli examples

# ૮. યુનિટ ટેસ્ટ્સ ચલાવો (Run Pytest)
python -m pytest tests/
```

## 📊 પુસ્તકની અંદાજિત કદ ગણતરી (Book Page Count)

- ૨૦૩ નય × ૨ પાના = **૪૦૬ પાના**
- ૭ ખંડ પ્રવેશ પ્રકરણો = **૧૪ થી ૨૮ પાના**
- પ્રસ્તાવના, પારિભાષિક કોશ, અનુક્રમણિકા = **~૨૦ પાના**
- **કુલ પુસ્તક**: આશરે **૪૪૦ થી ૪૫૫ પાના (A5 સાઈઝ)**, જે એક જ સુંદર ગ્રંથમાં ખૂબ આકર્ષક રીતે સમાઈ શકે છે.
