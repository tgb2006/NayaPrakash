# નય-ચક્ષુ: નયનું જ્ઞાન, સંશયનું સમાધાન
### સંક્ષિપ્ત ૨-પેજ આવૃત્તિ — 6.5 × 9.5 ઇંચ

## વર્તમાન HTML/PDF ડિઝાઇનનો આધાર

- [મુખ્ય ડિઝાઇન નિયમો](design/DESIGN_RULES.md): છેય ધારાઓ, લક્ષણ સૂત્ર, hanging numbers, joined ૧–૨–૧, padding, justification અને અંતિમ footer.
- [ચોક્કસ માપ અને strings](design/design_tokens.json): routine implementation માટે reference values; generator સાથે automatic integration હજી નથી.
- [કામ પહેલાં–પછી checklist](design/PRODUCTION_CHECKLIST.md): backup, ચાલુ HTMLમાં સીધો edit, browser checks અને અલગ PDF proof.
- [ચાલુ pilot HTML](pilot_chapter_001/chapter_001.html): refreshથી review કરવા માટે. પહેલાં અલગ `pilot_chapter_001/backups/<revision>/`માં backup લેવો.

**Design precedence:** ઉપરની નિયમાવલી વર્તમાન છે. નીચેનો અગાઉનો A5/ચાર-ધારા/word-budget અને page-count વર્ણન લેખન workflowની ઐતિહાસિક નોંધ છે; તેનો ઉપયોગ નવા print layoutનું માપ કે સંપૂર્ણ source ઘટાડવા માટે ન કરવો. વર્તમાન layoutમાં સાધનાધારા અને દર્શનધારા સહિત છ ધારાઓ છે. Actual chapters/page totals current catalogue અને measured paginationથી કાઢવા. અગાઉની QA/PDFને નવા HTMLનું proof ન માનવું.

જૈન દર્શનના ૨૦૩ નયો પર આધારિત આ સંક્ષિપ્ત આવૃત્તિ પુસ્તક નિર્માણ તંત્ર છે. આ આવૃત્તિ ખાસ કરીને **A5 સાઈઝના સામસામેના બે પાના (Facing 2 Pages)** માં પ્રત્યેક નયને 'ચાર ધારા' (તત્વધારા, કાવ્યધારા, કથાધારા, વિવેકધારા) ના અખંડ પ્રવાહમાં રસપ્રદ, આબાલગોપાલ સુબોધ, સ્વાદિષ્ટ અને તત્વસ્પર્શી શૈલીમાં રજૂ કરવા માટે રચાયેલ છે.

## 📖 ૨-પેજ A5 ધારા માળખું (Facing-Page Dhara Layout)

પ્રત્યેક અધ્યાય ચોક્કસ **૫૩૦ થી ૬૨૦ શબ્દો** માં બે સામસામેના પૃષ્ઠોમાં સુગ્રથિત થાય છે:

```
┌───────────────────────────────────────────────┐   ┌───────────────────────────────────────────────┐
│     ડાબું પાનું (PAGE 1: તત્વધારા & કાવ્યધારા)   │   │     જમણું પાનું (PAGE 2: કથાધારા & વિવેકધારા)   │
├───────────────────────────────────────────────┤   ├───────────────────────────────────────────────┤
│ • શીર્ષક અને સંક્ષિપ્ત આગમ પરિચય               │   │ • ## કથાધારા: [વાર્તા શીર્ષક] (૫૦%-૬૦% ભાગ)    │
│ • ## તત્વધારા (સંપૂર્ણ વિવેચન: ~૨૪૦-૨૭૦ શબ્દો) │   │   - ### પિપાસા: મૂંઝવણ, અટકળો, પ્રશ્નાર્થ     │
│   - **૧. રૂપક-દ્રષ્ટિ** (કેન્દ્રીય રૂપક)        │   │   - ### પાન: નય-દ્રષ્ટિથી સમાધાન, વિશ્રામ     │
│   - **૨. સ્વરૂપ-સૃષ્ટિ** (સરળ ઓળખ & લક્ષણ)    │   │ • ## વિવેકધારા (૪૦% ભાગ)                      │
│   - **૩. વ્યવહાર-પૃષ્ટિ** (જીવંત દૃષ્ટાંતો)    │   │   - ### એકાંત દર્શન: જડતા/કદાગ્રહના ગેરલાભ  │
│   - **૪. મર્મ-તુષ્ટિ** (સત્ય & ભ્રમણા-નિવારણ)  │   │   - ### અનેકાંત દર્શન: સમન્વયનું સૌંદર્ય      │
│ • ## કાવ્યધારા (૨ પંક્તિનો દોહરો: ~૨૦-૨૫ શબ્દો)│   │                                               │
│ (કુલ ડાબું પાનું: ~૨૩૦ થી ૩૦૦ શબ્દો)           │   │ (કુલ જમણું પાનું: ~૨૫૦ થી ૩૨૦ શબ્દો)           │
└───────────────────────────────────────────────┘   └───────────────────────────────────────────────┘
```

### ડાબું પાનું (PAGE 1: તત્વધારા અને કાવ્યધારા)
1. **## તત્વધારા (~૨૪૦ થી ૨૭૦ શબ્દો)**:
   - **૧. રૂપક-દ્રષ્ટિ**: કેન્દ્રીય રૂપક કે મનોહર ઉપમા દ્વારા નયનું ઉદ્ઘાટન.
   - **૨. સ્વરૂપ-સૃષ્ટિ**: કાળના પડદા પાર જોતી સરળ ઓળખ અને આગમ લક્ષણ.
   - **૩. વ્યવહાર-પૃષ્ટિ**: રોજિંદા જીવન, સંબંધો અને પ્રકૃતિના જીવંત દૃષ્ટાંતો.
   - **૪. મર્મ-તુષ્ટિ**: નયનો સાચો આશય અને તેની મર્યાદા સરળતાથી સમજાવી, દ્રવ્યનું સાતત્ય અને પર્યાયોના કાળગત પરિવર્તન વચ્ચેનો ભેદ જાળવવો.
2. **## કાવ્યધારા (~૨૦-૨૫ શબ્દો)**:
   - કેવળ ૨ પંક્તિનો ગેય દોહરો જેમાં નયનું યથાર્થ સ્વરૂપ કંઠસ્થ થઈ જાય છે.

### જમણું પાનું (PAGE 2: કથાધારા અને વિવેકધારા)
1. **## કથાધારા: [વાર્તા શીર્ષક] (૫૦% થી ૬૦% ભાગ - ~૧૫૦-૧૮૦ શબ્દો)**:
   - **### પિપાસા**: વ્યક્તિની મૂંઝવણ, અટકળો, વર્તુળોમાં અટકી પડવું અને પ્રશ્નાર્થ: *"આમાંથી શું રસ્તો?"*
   - **### પાન**: નય-દ્રષ્ટિ દ્વારા મૂંઝવણનું નિવારણ, માર્ગ, મંઝિલ અને ભીતરમાં અપૂર્વ વિશ્રામ.
2. **## વિવેકધારા (૪૦% ભાગ - ~૧૧૦-૧૩૦ શબ્દો)**:
   - **### એકાંત દર્શન (૨૦% ભાગ)**: આ નય-દ્રષ્ટિ જો જીદ કે જડ બને તો થતી સંકુચિતતા અને નુકસાન.
   - **### અનેકાંત દર્શન (૨૦% ભાગ)**: આજ નય-દ્રષ્ટિ જો યાત્રા અને સમન્વય બને તો પ્રગટતું પરમ સૌંદર્ય.

## 🛠️ કમાન્ડ લાઈન ઈન્ટરફેસ (CLI Commands)

```powershell
cd sankshipt

# ૧. પ્રગતિ સ્થિતિ જુઓ (Status Dashboard)
python -m src.cli status

# ૨. કોઈ નય માટે લેખન પ્રોમ્પ્ટ મેળવો (Generate Prompt for Naya ID)
python -m src.cli prompt --id 2

# ૩. લખાયેલ અધ્યાયની પાના-વાર શબ્દસંખ્યા અને અહિંસા ચકાસો (Validate)
python -m src.cli validate --file output/khanda_1_naigam/chapter_001_bhuta_naigam_naya_gu.md

# ૪. અધ્યાય ચકાસીને ટ્રેકરમાં રજિસ્ટર કરો (Register)
python -m src.cli register --file output/khanda_1_naigam/chapter_001_bhuta_naigam_naya_gu.md --id 1

# ૫. સંપૂર્ણ પુસ્તક અને અનુક્રમણિકા સંકલિત કરો (Compile Master Book)
python -m src.cli compile

# ૬. નોંધાયેલા પ્રસંગો/કથાઓ જુઓ
python -m src.cli examples

# ૭. યુનિટ ટેસ્ટ્સ ચલાવો (Run Pytest)
python -m pytest tests/
```

- **કુલ પુસ્તક**: આશરે **૪૩૫ થી ૪૪૫ પાના (A5 સાઈઝ)**, જે એક જ સુંદર ગ્રંથમાં અત્યંત આકર્ષક રીતે સમાઈ જશે.
